Правила перевода

Из любой системы в 10-ю

Расписываем число по разрядам: каждая цифра умножается на основание в степени её позиции (считая справа налево, начиная с 0).

Пример: 1011₂ = 1·2³ + 0·2² + 1·2¹ + 1·2⁰ = 8 + 0 + 2 + 1 = 11₁₀

Пример: 2F₁₆ = 2·16¹ + 15·16⁰ = 32 + 15 = 47₁₀

Из 10-й в любую

Делим число на основание, записываем остаток. Продолжаем, пока не получим 0. Затем выписываем остатки снизу вверх.

Пример: 13₁₀ → 2-я

13÷ 2=6ост. 1
6÷ 2=3ост. 0
3÷ 2=1ост. 1
1÷ 2=0ост. 1

Остатки снизу вверх: 1 1 0 1

Значит, 13₁₀ = 1101₂.

Проверка: 1·8 + 1·4 + 0·2 + 1·1 = 13

Пример: 45₁₀ → 16-я

45÷ 16=2ост. 13 → D
2÷ 16=0ост. 2

Остатки снизу вверх: 2 D

Значит, 45₁₀ = 2D₁₆.

Проверка: 2·16 + 13 = 45

Через двоичную (для 8 и 16)

8 ⇄ 2: каждая восьмеричная цифра — это ровно 3 бита (триада).
Пример: 57₈ = 101 111₂ = 101111₂

16 ⇄ 2: каждая шестнадцатеричная цифра — ровно 4 бита (тетрада).
Пример: 2F₁₆ = 0010 1111₂ = 101111₂

8 ⇄ 16: переводите через двоичную: сначала в 2-ю, затем группируйте по 3 или по 4 бита.
